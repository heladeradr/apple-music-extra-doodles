# Apple Music extra doodles

Userscript for the Apple Music web app / PWA (`music.apple.com`): adds a Liquid Glass distortion effect to the player bar, search box and scope pills, plus a few helpers.

## Install

Needs a userscript manager (Violentmonkey / Tampermonkey). Click to install:

**[apple-music-extra-doodles.user.js](https://raw.githubusercontent.com/heladeradr/apple-music-extra-doodles/main/apple-music-extra-doodles.user.js)**

## Updates

The script has `@updateURL` / `@downloadURL` pointing at the raw file on `main`. Your userscript manager will pick up new versions automatically, as long as the `@version` in the header is bumped with each change.
